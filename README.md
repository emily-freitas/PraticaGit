## ✅ O que aprendi até agora:

### 🐙 Comandos básicos do Git

- `git init` - Iniciar repositório
- `git status` - Verificar status das alterações
- `git add .` - Preparar arquivos para commit
- `git commit -m "mensagem"` - Registrar alterações
- `git push` - Enviar para o GitHub
- `git pull` - Baixar alterações do GitHub

### 🌿 Branches

- `git branch` - Listar branches
- `git checkout -b nome-branch` - Criar e mudar para nova branch
- `git checkout nome-branch` - Mudar entre branches
- `git push -u origin nome-branch` - Enviar branch nova para o GitHub

### 🔀 Pull Requests

- Criar Pull Request pelo GitHub
- Fazer `compare & pull request`
- Revisar mudanças na aba "Files changed"
- Fazer merge após aprovação

### 🛡️ Proteção de branches

- Configurar `Branch protection rule`
- Exigir Pull Request para a `main`
- Exigir approvals antes do merge
- Bloquear force pushes

### 🤖 CI com GitHub Actions

- Criar pasta `.github/workflows/`
- Adicionar arquivo `ci.yml`
- Automatizar verificações em cada PR
